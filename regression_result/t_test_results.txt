TECHNICAL NOTES
================================================================================

Test Method: Welch's t-test (independent samples)
- Does NOT assume equal variances (more conservative)
- Recommended for unequal sample sizes or variances
- Degrees of freedom adjusted using Welch-Satterthwaite equation

Effect Size Calculation: Cohen's d (pooled)
  d = |M1 - M2| / SDpooled
  Where SDpooled = sqrt[((n1-1)*SD1² + (n2-1)*SD2²) / (n1+n2-2)]

- Computed using t-distribution with Welch-Satterthwaite df
