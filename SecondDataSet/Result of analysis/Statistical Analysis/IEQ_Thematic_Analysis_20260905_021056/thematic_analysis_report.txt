METHODOLOGICAL NOTES
================================================================================
- Continuous variables: Pearson correlations feed the EFA and the clustering
  distance metric (1 - |r|), appropriate for approximately interval-scaled data
  such as CFA/BCFA factor scores.
- Ordinal variables: Polychoric correlations are used instead of Pearson, since
  Likert-type items are ordered categories rather than continuous measurements;
  polychoric correlations estimate the correlation between the assumed latent
  continuous variables underlying the observed ordinal responses (Olsson, 1979).
- The number of themes/factors is chosen via parallel analysis (Horn, 1965),
  which retains factors whose eigenvalues exceed those from randomly generated
  data of the same dimensions, avoiding both over- and under-extraction.
- Oblique (oblimin) rotation is used by default because psychological/behavioural
  themes are rarely uncorrelated in reality.
- The Adjusted Rand Index (Hubert & Arabie, 1985) corrects the raw agreement rate
  for the agreement expected by chance alone, given the size of each theme/cluster.
